# Azure Data Fundamentals (DP-900) - Requirements

## Overview

This exercise aligns with the **Microsoft Certified: Azure Data Fundamentals** certification and is intended for learners who are beginning to work with data in Microsoft Azure.

The certification validates foundational knowledge of:

- Core data concepts
- Relational data in Azure
- Non-relational data in Azure
- Analytics workloads in Azure

---

## Target Audience

Candidates should be familiar with:

- Relational and non-relational data concepts
- Transactional and analytical workloads
- Basic cloud computing concepts
- Azure fundamentals (recommended but not required)

This certification is designed for:

- Students
- Data analysts
- Business users
- Cloud beginners
- IT professionals transitioning to Azure data technologies

---

## Learning Objectives

Upon completion, learners should be able to:

### 1. Describe Core Data Concepts

- Understand structured, semi-structured, and unstructured data
- Explain transactional and analytical workloads
- Differentiate batch and streaming data
- Understand data visualization and business intelligence concepts
- Describe ETL and ELT processes

### 2. Identify Considerations for Relational Data on Azure

- Understand relational database concepts
- Work with tables, indexes, keys, and views
- Recognize Azure SQL offerings:
  - Azure SQL Database
  - Azure SQL Managed Instance
  - SQL Server on Azure Virtual Machines
- Understand basic SQL querying concepts
- Identify security and connectivity considerations

### 3. Describe Considerations for Non-Relational Data on Azure

- Understand NoSQL and non-relational data structures
- Identify document, key-value, graph, and column-family databases
- Understand Azure Cosmos DB capabilities
- Recognize Azure Storage services:
  - Blob Storage
  - Table Storage
  - File Storage

### 4. Describe Analytics Workloads on Azure

- Understand data warehousing concepts
- Identify analytics solutions in Azure
- Understand:
  - Microsoft Fabric
  - Azure Synapse Analytics
  - Azure Databricks
  - Power BI
- Describe data ingestion, transformation, and visualization processes

---

## Prerequisites

### Required

None.

### Recommended

- Basic computer literacy
- Familiarity with cloud concepts
- Access to an Azure subscription for hands-on exercises

---

## Skills Measured

| Domain | Description |
|----------|------------|
| Core Data Concepts | Foundational data principles and workloads |
| Relational Data on Azure | Azure SQL and relational database services |
| Non-Relational Data on Azure | Azure Cosmos DB and storage services |
| Analytics Workloads on Azure | Modern analytics, BI, and data warehousing |

---

## Success Criteria

Learners can:

- Explain key data concepts
- Distinguish relational and non-relational solutions
- Select appropriate Azure data services
- Understand analytical workloads
- Demonstrate readiness for the DP-900 certification exam
