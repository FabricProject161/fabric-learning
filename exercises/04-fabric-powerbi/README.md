# Exercise 04: Create Your First Report

## Objective

Connect Power BI to Fabric and create a report.

## Scenario

Management wants to monitor product sales.

## Tasks

### Task 1: Create Semantic Model

Use the warehouse created previously.

### Task 2: Create Relationships

Connect fact and dimension tables.

### Task 3: Create Visuals

Create:

- Revenue by Product
- Revenue by Month
- Top Products

### Task 4: Publish Report

Save report as:

```text
Sales Dashboard
```

## Deliverables

- Report screenshot
- Semantic model screenshot

## Success Criteria

- Semantic model created
- Visuals working
- Report published

## Bonus Challenge

Create KPI cards for:

- Total Revenue
- Average Order Value
- Total Orders
