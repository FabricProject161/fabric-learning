# Exercise 02: Build Your First Pipeline

## Objective

Learn how to automate data movement using Fabric Data Factory.

## Scenario

A CSV file arrives every day and must be copied into a Lakehouse.

## Tasks

### Task 1: Create Pipeline

Create a new pipeline named:

```text
DailySalesPipeline
```

### Task 2: Add Copy Activity

Configure:

Source:

```text
CSV File
```

Destination:

```text
SalesLakehouse
```

### Task 3: Run Pipeline

Trigger the pipeline manually.

### Task 4: Review Monitoring

Open:

```text
Monitor Hub
```

Review execution results.

## Deliverables

- Pipeline screenshot
- Successful pipeline run screenshot
- Monitoring screenshot

## Success Criteria

- Pipeline created
- Data copied successfully
- Run appears in monitoring

## Challenge

Create a second pipeline that loads customer data.
